# 大馆密档｜工作与工作流总结

整理日期：2026-11-14。覆盖2026-10-13至11月12日可读取记录，按周一至周日归周，仅列出有工作更新的阶段。

## 产出精简说明

保留 8 个主要压缩包与代表性图片：早期地图交互、V4.1 分享版、第一章独立交付和压缩素材、第二章单屏布局里程碑及整合版、第三章最终整合版、第四章整合版。重复中间包及已被整合版覆盖的单点位包不再收录；制作过程仍保留在文字记录中。原始文件仍保留在工作目录。

## 我的工作定位

我负责结合美术组已有的美术素材与资产，补全 UI 和解谜过程中需要的美术资源，并借助 AI 产出适配技术组微信小程序开发环境的基础交互代码。具体工作包括梳理交互所需资产、复用与调整正式人物和场景、补充缺失素材、优化页面布局与操作反馈，以及按点位整理素材和代码供技术组接入。

美术组提供已有的视觉设定与正式资产；我的工作侧重在此基础上的补全、适配和交互实现；技术组负责项目开发环境中的接入与后续工程工作。AI 辅助代码与素材制作，我负责需求表达、视觉和交互判断、迭代反馈及交付整理。

## 从记录提炼的工作流

读取交互需求与技术组开发约束 → 对照美术组已有素材和资产 → 明确需要复用、适配与补全的内容 → 固定手机视口并规划页面布局 → 补充 UI 与解谜美术资源、压缩素材 → 借助 AI 实现基础交互代码 → 结合实际页面检查信息、操作与视觉 → 按反馈迭代 → 按点位整理资源与代码，交给技术组接入微信小程序环境。

这条工作流是回顾总结，并非每一周都严格执行；11月10日明确提出“先尺寸、再布局、再美术”，是协作方式的重要调整。

## 主要修改的共同方向

- 让每一步有信息目标：避免将“身份未确认”再拖入“未确认”框的循环操作。
- 减少阅读与层级：合并重复材料对照，关系选项直接显示，删除重复弹窗和中转反馈。
- 区分事实与推论：没有看见不能当作没有发生，缺少原文支持的剧情与结算撤回。
- 让美术服务交互：人物头像参与关系和材料辨识，保留正式角色颜色，纸质文件夹帮助归档。
- 克制动效：更正揭示和盖章可强调，普通对白不需要每次都动。
- 交付有明确范围：网页原型、素材包、小程序工程分别说明；云端压缩版中断不冒称完成。

## 第04阶段｜11月9—15日（截至11月12日记录）

**主题：第二至第四章、单屏布局与资源交付**

### 做了什么、更新了什么

11月10日提取第一章当前版图片，明确素材按点位命名和归档；初始6个P1-1素材上传有历史完成说明，后续压缩版重传中断，不记为全部上传完成。要求图片150—250KB、复用正式人物资料，第二章先做证词链/关系图/双线时间轴。转达前端固定手机单屏、避免上下滚动要求，并明确先布局后美术的制作顺序。11月12日继续简化头像细节、统一风格，指出拖拽、字体和关系弹窗问题；反复追问每一步要让玩家知道什么，删除循环论证与重复阅读。第二章逐步转为对白和显眼结论、关系图与轻量核查。第三章围绕死因材料、会谈与认罪动机，合并重复页面、保留必要选择，增加律师表情、固定继续按钮。第四章以更正证词和三条盖章判断为核心，增加纸质案卷，删除重复弹窗和多余动画，分开归档与剧情收尾；最终接入P4-2并复用已有素材控制成本。

### 我的主要贡献与判断

我承担叙事目标校验、交互减负、正式人物辨识与色彩一致性、资源体积和交付版本把控。在此基础上，我根据原型交互文档制作高保真 UI，完成文档要求的全部交互，并将代码打包、转换到微信小程序开发工具中，供技术组继续接入。这里的“全部交互”指本轮原型交互文档所要求的范围，不扩展为全部游戏功能或上线验收。
